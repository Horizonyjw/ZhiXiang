# 智象：面向航空港异常天气建模的自主研究智能体系统

> **版本**：V0.1  
> **项目周期**：4～5周集中开发期

## 项目简介

“智象”以雷达回波短临预测为首个验证任务，逐步建设“数据治理 → 基线预测 → 神经算子建模 → 统一评测 → 自主实验优化 → 航空运行解释”的可运行、可复现、可比较研究流程。

本项目当前聚焦算法与自主研究智能体原型验证，不替代正式气象预报系统或空管运行决策系统。项目推进以可检查的代码、数据、日志、指标和结果图为依据。

## 项目目标

- 建立统一的数据治理、连续样本生成、数据划分和数据接口流程；
- 形成 Persistence、学习型基线与神经算子模型的统一对比；
- 使用统一数据划分、评测指标和实验记录方式保障结果可比、可追溯；
- 在标准化训练和评测流程基础上，构建受控的自主实验优化闭环；
- 为后续航空运行解释、项目材料和论文研究保留可靠证据。

## 协作原则

- 开始任何模块工作前，先阅读项目规划和协作要求；
- 所有模型遵守统一数据接口、数据划分和评测口径；
- 真实数据、模型权重和大量预测结果不提交到 Git 仓库；
- 每次实验都必须保留配置、代码版本、数据版本、日志、指标和结果图；
- 未经确认的数据单位、缺失值定义、阈值、公共接口或划分方式不得自行假设或修改。
