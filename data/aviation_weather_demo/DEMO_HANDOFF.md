# B1 演示交接说明

## 用途

本目录用于在原始雷达 PNG 尚未交付到当前工程时，先演示数据接口和模型对接流程。

当前演示包包含 **20 组接口样本**，对应任务单中“10～20 组小规模样本用于联调”的最低阶段要求。

## 接口

```text
N    = 20
Tin  = 5
Tout = 3
C    = 1
H    = 352
W    = 512
dt   = 6 min
dtype = float32
```

文件：

```text
demo/demo_20_samples.npz
```

字段：

```text
inputs        [20, 5, 1, 352, 512]
targets       [20, 3, 1, 352, 512]
metadata_json JSON 字符串
```

## 重要说明

当前对话提供的是数据处理方案、数据规模统计、任务要求和代码工程，没有提供那批原始雷达 PNG。

因此本演示包中的数组值只用于验证：

- shape；
- dtype；
- 字段名；
- batch 接口；
- 时间 metadata；
- 模型侧代码能否完成对接。

**这些数组值不代表实测雷达观测，不得用于训练效果、评测指标或气象结论。**

时间 metadata 按已有材料中的规则组织：

```text
起始参考时刻：2026-01-23 18:00
时间间隔：6 min
过去 5 帧 → 未来 3 帧
```

正式数据到达后，直接使用工程中的真实数据 pipeline 替换本演示文件，模型输入输出接口保持一致。
