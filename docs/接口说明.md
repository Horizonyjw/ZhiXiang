# 数据、模型和评测接口说明

> **状态**：接口规范占位。本文规定公共格式与后续产物命名，不表示已有数据、模型、评测程序或实验结果。

## 1. 公共张量接口

~~~text
模型输入：[B, Tin, C, H, W]
模型输出：[B, Tout, C, H, W]
默认数据类型：float32
~~~

| 维度 | 含义 | 实际取值 |
| --- | --- | --- |
| B | 批量大小 | 【待配置】 |
| Tin | 历史输入帧数 | 【待确认】 |
| Tout | 未来预测帧数 | 【待确认】 |
| C | 通道数 | 【待确认】 |
| H、W | 空间高度、宽度 | 【待确认】 |

## 2. DataLoader 返回内容

后续 DataLoader 应至少返回以下内容：

| 字段 | 预期形状 / 类型 | 用途 |
| --- | --- | --- |
| inputs | [B, Tin, C, H, W] | 历史输入序列 |
| targets | [B, Tout, C, H, W] | 真实未来序列 |
| metadata | 字典或等效结构 | 样本编号、时间、数据来源等追溯信息 |
| valid_mask | 【待确认是否需要】 | 缺失值或无效区域的标记 |

缺失值、无回波、归一化、裁剪、降采样和单位转换的具体规则均为【待确认】；不得在未确认前自行实现或假设。

## 3. 预测结果与评测读取约定

以下为后续实现应遵守的命名和位置约定：

| 产物 | 约定位置 | 当前状态 |
| --- | --- | --- |
| 实验配置 | configs/<experiment_id>.yaml | 【待创建】 |
| 模型权重 | results/<experiment_id>/checkpoints/ | 【待生成】 |
| 预测结果 | results/<experiment_id>/predictions.npz | 【待生成】 |
| 指标文件 | results/<experiment_id>/metrics.json 或 metrics.csv | 【待生成】 |
| 结果图 | results/<experiment_id>/figures/ | 【待生成】 |
| 评测读取位置 | results/<experiment_id>/predictions.npz | 【待实现】 |

评测程序后续只应读取已保存的预测结果和对应配置，不应在评测时重新选择样本或修改阈值。

## 4. 实验编号

统一采用以下格式：

~~~text
YYYYMMDD-模型-数据版本-序号
~~~

示例值由实际实验产生后再登记；当前不提供虚构实验编号。

## 5. 接入前检查

- [ ] 数据来源、授权、字段、单位与缺失值定义已确认；
- [ ] Tin、Tout、时间间隔、空间处理和阈值已写入配置；
- [ ] 输入与输出维度通过实际数据检查；
- [ ] 预测保存、评测读取和结果图命名已由实际运行验证；
- [ ] 实验记录包含配置、代码版本、日志、指标和结果图。
