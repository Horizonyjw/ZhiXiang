# 数据、模型和评测接口说明

> **状态**：已对齐 `radar_v1`（与 [wjh](https://github.com/Horizonyjw/ZhiXiang/tree/wjh) U-Net handoff 联调一致）。

## 1. 公共张量接口

```text
模型输入：[B, Tin, C, H, W] = [B, 5, 1, 352, 512]
模型输出：[B, Tout, C, H, W] = [B, 3, 1, 352, 512]
默认数据类型：float32
数值范围：[0, 1] 归一化灰度代理（不是物理 dBZ）
data_version：radar_v1
```

| 维度 | 含义 | 实际取值 |
| --- | --- | --- |
| B | 批量大小 | 由配置决定 |
| Tin | 历史输入帧数 | 5 |
| Tout | 未来预测帧数 | 3 |
| C | 通道数 | 1 |
| H、W | 空间高度、宽度 | 352、512 |

## 2. DataLoader / handoff 返回内容

| 字段 | 形状 / 类型 | 用途 |
| --- | --- | --- |
| inputs | [B, 5, 1, 352, 512] float32 | 历史输入序列 |
| targets | [B, 3, 1, 352, 512] float32 | 真实未来序列 |
| metadata / metadata_json | 字典或 JSON | 样本编号、时间、片段等 |

快速联调文件：

```text
radar_v1/04_handoff/handoff_samples.npz
```

字段：`inputs`、`targets`、`metadata_json`（样本数 N=16）。

## 3. 预测结果与评测读取约定

| 产物 | 约定位置 |
| --- | --- |
| 实验配置 | `configs/<experiment_id>.yaml` |
| 预测结果 | `results/<experiment_id>/predictions.npz` |
| 指标文件 | `results/<experiment_id>/metrics.json` |

`predictions.npz` 推荐字段：`inputs`、`targets`、`predictions`、`metadata_json`。

评测 v0.2：在 `[0,1]` 灰度上计算 MAE / MSE；CSI / POD / FAR 暂不计算。

## 4. 实验编号

```text
YYYYMMDD-模型-数据版本-序号
```

示例：`20260814-persistence-radar_v1-01`、`20260812-unet-radar_v1-01`。
