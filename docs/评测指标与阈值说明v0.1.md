# 评测指标与阈值说明 v0.1

## 1. 第一阶段指标

第一阶段统一计算以下指标：

| 指标 | 计算方法 | 方向 |
| --- | --- | --- |
| MAE | 所有有效格点的“预测值 − 真值”的绝对值之和 ÷ 有效格点数 | 越小越好 |
| MSE | 所有有效格点的“预测值 − 真值”的平方之和 ÷ 有效格点数 | 越小越好 |
| CSI | 命中 ÷（命中 + 漏报 + 空报） | 越大越好 |
| POD | 命中 ÷（命中 + 漏报） | 越大越好 |
| FAR | 空报 ÷（命中 + 空报） | 越小越好 |

其中，“命中”表示预测和真值都达到 20.0 dBZ；“漏报”表示真值达到但预测未达到；“空报”表示预测达到但真值未达到。

MAE 与 MSE 同时输出，其中 MAE 作为主要连续误差指标，MSE 用于观察较大误差。

## 2. 回波阈值

CSI、POD 和 FAR 的第一阶段统一回波阈值为 **20.0 dBZ**。

```text
预测值 ≥ 20.0 dBZ，且真值 ≥ 20.0 dBZ：命中（H）
预测值 < 20.0 dBZ，且真值 ≥ 20.0 dBZ：漏报（M）
预测值 ≥ 20.0 dBZ，且真值 < 20.0 dBZ：空报（F）
```

该阈值只适用于单位为 dBZ 的雷达反射率数据。若实际数据不是 dBZ，须在确认转换方式后再计算分类指标。

## 3. 缺失区域处理

- `NaN`、填充值和质量控制标记为无效的格点不参与任何指标计算；
- 无回波区域不是缺失值，应作为“未达到阈值”的有效格点参与计算；
- 预测值或真值任一方无效时，该格点排除。

## 4. 逐预测步长统计

**分别统计每个预测步长**

对未来的每一帧，分别计算 MAE、MSE、CSI、POD 和 FAR，以比较不同预测时效下的效果。
