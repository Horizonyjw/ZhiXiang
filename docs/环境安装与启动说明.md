## 2. 推荐安装（venv + pip）

在仓库根目录执行（PowerShell）：

```powershell
cd <仓库根目录>

# 1) 创建虚拟环境
py -3.12 -m venv .venv
# 若只有 3.13：py -3.13 -m venv .venv

# 2) 激活
.\.venv\Scripts\Activate.ps1

# 3) 安装 PyTorch（按本机 CUDA 驱动选择官方命令，示例为 CUDA 12.8/12.9 一类）
# 请打开 https://pytorch.org 核对最新 index-url，勿盲目复制过期链接
python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cu128

# 4) 安装其余依赖
python -m pip install -r env/requirements.txt
```

若本机仅有 CPU，可改为：

```powershell
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -r env/requirements.txt
```

可选 Conda：参考 `env/environment.yml`，仍需按本机 CUDA 安装匹配的 `torch`。

## 3. 最小启动命令

均在**仓库根目录**执行：

```powershell
# 环境检查
python -m train.check_env

# Persistence / FNO 随机张量前向（接口已对齐 radar_v1：5→3，352×512）
python -m train.test_persistence_forward
python -m train.test_fno_forward

# 真实 handoff 前向（需 radar_v1/04_handoff/handoff_samples.npz）
python -m train.test_persistence_handoff
python -m train.test_fno_handoff
```

若使用项目 venv：

```powershell
.\.venv\Scripts\python.exe -m train.check_env
```

### radar_v1 handoff 说明

- 路径：`radar_v1/04_handoff/handoff_samples.npz`（仓库相对路径）
- 形状：`inputs [16,5,1,352,512]`，`targets [16,3,1,352,512]`，`float32`，`[0,1]`
- 该文件走 Git LFS；若检出后只有指针，执行 `git lfs pull -I radar_v1/04_handoff/handoff_samples.npz`
- Persistence：`results/20260814-persistence-radar_v1-01/`
- FNO 过拟合：`results/20260814-fno-radar_v1-overfit-01/`（`python -m train.overfit_fno_handoff`）
- 全量原始 PNG 不入库；需要时按数据侧说明自行配置本机路径，勿提交 `configs/local_*.yaml`

## 4. 常见问题记录

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| `torch.cuda.is_available() == False` | 安装了 CPU 版 torch，或驱动/CUDA 不匹配 | 用 `python -c "import torch; print(torch.__version__, torch.version.cuda)"` 核对；重装对应 CUDA 轮子 |
| `ModuleNotFoundError: yaml` | 未装 PyYAML | `pip install -r env/requirements.txt` |
| `ModuleNotFoundError: models` | 不在仓库根目录运行 | `cd` 到含 `models/`、`train/` 的根目录后再执行 `-m` |
| `找不到 handoff` / npz 打不开 | LFS 未拉取，文件仍是指针 | `git lfs pull -I radar_v1/04_handoff/handoff_samples.npz` |
| Tin/Tout 与配置不一致 | 仍用旧占位配置（Tout=5, 128×128） | 使用 `configs/20260814-*-radar_v1-01.yaml` |
| 路径写死盘符 | 个人机器路径不同 | 代码与配置一律用相对仓库根路径 |
| Python 3.13 装不上旧包 | 部分轮子尚未支持 3.13 | 改用 3.10–3.12 重建 venv |
