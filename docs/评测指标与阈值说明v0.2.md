# 评测指标与阈值说明 v0.2

## 1. 第一阶段指标

第一阶段沿用 v0.1 的五项评测指标。其中，MAE 和 MSE 改为直接基于归一化灰度值计算；CSI、POD 和 FAR 因当前缺少确定阈值所需的数据说明，暂不计算。

| 指标 | 计算方法 | 方向 | 当前状态 |
| --- | --- | --- | --- |
| MAE | 所有有效格点的“预测灰度值 − 真实灰度值”的绝对值之和 ÷ 有效格点数 | 越小越好 | 计算 |
| MSE | 所有有效格点的“预测灰度值 − 真实灰度值”的平方之和 ÷ 有效格点数 | 越小越好 | 计算 |
| CSI | 命中 ÷（命中 + 漏报 + 空报） | 越大越好 | 暂不计算 |
| POD | 命中 ÷（命中 + 漏报） | 越大越好 | 暂不计算 |
| FAR | 空报 ÷（命中 + 空报） | 越小越好 | 暂不计算 |

MAE 与 MSE 同时输出，其中 MAE 作为主要连续误差指标，MSE 用于观察较大灰度误差。预测值和真实值均采用 `[0,1]` 范围内的归一化灰度值，不进行其他数值尺度转换。

## 2. 回波阈值

CSI、POD 和 FAR 必须先确定统一的活动回波阈值，才能划分命中、漏报和空报：

```text
预测值达到阈值，且真值达到阈值：命中（H）
预测值未达到阈值，且真值达到阈值：漏报（M）
预测值达到阈值，且真值未达到阈值：空报（F）
```

当前版本不指定具体阈值，也不计算 CSI、POD 和 FAR。

原因是原始雷达图采用不同颜色表示不同回波强度，但当前资料中没有提供完整的“RGB 颜色—回波强度等级”色标。数据处理侧已经检查过标准灰度转换以及直接在 `[0,1]` 归一化灰度上设置阈值的方案，但标准灰度公式反映的是视觉亮度，不能严格保持雷达颜色所表示的回波强弱顺序。因此，不能根据当前灰度值确定具有明确回波强度含义的活动回波阈值。

在获得完整色标并形成统一的颜色—强度映射之前，不根据灰度分布自行猜测阈值，也不针对不同模型分别调整阈值。

## 3. 缺失区域处理

- `NaN`、填充值和质量控制标记为无效的格点不参与 MAE 和 MSE 计算；
- 无回波区域不是缺失值，应作为有效格点参与 MAE 和 MSE 计算；
- 预测值或真值任一方无效时，该格点排除；
- 当前标准化数据将透明无效显示区域填为 `0`，如果没有单独提供有效区域掩码，评测侧无法区分无效区域和真实无回波区域。正式评测前需要数据侧补充有效区域掩码或等价说明。

## 4. 逐预测步长统计

**分别统计每个预测步长。**

对未来的每一帧分别计算 MAE 和 MSE，以比较不同预测时效下的灰度误差。

CSI、POD 和 FAR 保留为待计算指标；待颜色—强度映射和活动回波阈值确定后，再在后续版本中启用，并对所有对比模型使用同一阈值重新评测。

## 5. 当前版本结论

- MAE：可计算，使用归一化灰度值；
- MSE：可计算，使用归一化灰度值；
- CSI：阈值未确定，暂不计算；
- POD：阈值未确定，暂不计算；
- FAR：阈值未确定，暂不计算。
